# Application Visual Theme

Use the provided reference image as the visual source of truth for the application's overall visual identity.

The application is a modern fintech/trading platform with a premium, professional, data-focused aesthetic. The UI should feel like a polished financial trading product rather than a generic admin dashboard.

## Overall Visual Style

The design should be:

- Modern and premium
- Clean and minimal
- Professional and trustworthy
- Data-focused
- Spacious without feeling empty
- Visually calm despite displaying financial information
- Consistent across every page and feature

Use a dark green / black foundation with bright green accents as the primary visual identity.

The UI should use rounded cards, subtle borders, restrained shadows, compact controls, and strong typography hierarchy.

Avoid:

- Generic Bootstrap/admin-dashboard styling
- Excessive gradients
- Excessive shadows
- Excessive use of bright colors
- Overly decorative UI
- Excessively rounded/pill-shaped elements
- Pure black backgrounds throughout the interface

---

## Color Identity

Green is the primary brand color.

Green should be used for:

- Primary actions
- Active navigation
- Selected states
- Positive financial values
- Positive price movement
- Important highlights
- Charts
- Success states
- Focus/interaction accents

Green should be an accent rather than covering large portions of the interface.

Use neutral colors for the majority of the interface's backgrounds, surfaces, text, and supporting UI elements.

### Dark Theme

The dark theme should be the closest representation of the provided reference image.

Use a very dark green-black as the primary application background rather than pure black.

Visual hierarchy:

```text
Very dark green-black
    ↓
Dark green-black navigation/surfaces
    ↓
Slightly lighter cards and panels
    ↓
Subtle green-gray borders
    ↓
Off-white primary text
    ↓
Muted gray-green secondary text
    ↓
Bright lime-green accents
```

Dark theme characteristics:

- Deep green-black backgrounds
- Dark green cards and panels
- Subtle borders
- Off-white primary text
- Muted gray-green secondary text
- Bright lime-green primary actions
- Green positive values
- Dark input fields
- Subtle green highlights
- Restrained shadows/glows

The overall appearance should resemble a sophisticated trading terminal.

### Light Theme

The light theme should preserve the same visual identity rather than becoming a generic white application.

Use:

- White primary surfaces
- Very light neutral or green-tinted backgrounds
- Very subtle green-tinted secondary surfaces
- Light gray/green borders
- Dark green primary text
- Muted green-gray secondary text
- Strong green primary accents

Visual hierarchy:

```text
Very light background
    ↓
White cards and panels
    ↓
Subtle green-gray borders
    ↓
Dark green typography
    ↓
Green accents and actions
```

The light theme should feel clean, bright, modern, and premium while remaining recognizably part of the same product as the dark theme.

---

## Layout Language

Use a dashboard-oriented layout with clearly separated content areas.

The design language should favor:

- Side navigation
- Top-level application header
- Content panels
- Information cards
- Financial summary sections
- Data tables
- Charts
- Forms
- Compact controls
- Clearly separated sections

Large content areas should be organized into cards/panels rather than appearing as one large undifferentiated page.

Cards should have:

- Rounded corners
- Consistent padding
- Subtle borders
- Minimal shadows
- Clear internal hierarchy

Cards should look like financial information panels rather than generic UI containers.

---

## Navigation

Navigation should be visually lightweight and integrated into the application rather than dominating the page.

Navigation items should clearly distinguish:

- Active
- Inactive
- Hover
- Selected
- Disabled

The active navigation state should use the green brand accent and/or a subtle green-tinted background.

The navigation should feel similar to the sidebar in the reference image: dark, minimal, compact, and focused.

---

## Typography

Use a modern sans-serif typography style.

Typography should create a strong hierarchy:

- Large, prominent numerical values
- Clear page titles
- Medium/semibold section headings
- Readable body text
- Smaller muted metadata

Financial numbers such as:

- Account balances
- Prices
- Quantities
- Profit/loss
- Order values
- Portfolio values

should receive strong visual emphasis.

Avoid excessive uppercase text.

---

## Financial UI

The application should visually communicate financial information efficiently.

Positive financial movement should use the primary green accent.

Negative movement should use a restrained red.

Neutral information should use the normal text palette.

Use color intentionally rather than decorating every piece of information.

Financial data should be easy to scan at a glance.

Charts should use the green brand identity as their primary visual accent, with subtle supporting elements and restrained gridlines.

Tables should use subtle row separators rather than heavy borders around every cell.

---

## Buttons and Controls

Primary actions should be visually prominent and use the green brand color.

Secondary actions should be more subdued.

Controls should have:

- Consistent sizing
- Consistent corner radius
- Clear hierarchy
- Subtle borders
- Clear hover states
- Clear active states

Primary buttons should have a strong green presence without appearing oversized.

---

## Forms

Forms should visually integrate with the surrounding trading interface.

Inputs should use the theme's surface colors and subtle borders.

Dark mode inputs should use dark green surfaces.

Light mode inputs should use white or very light surfaces.

Form controls should feel compact, clean, and professional.

---

## Icons

Use a consistent, minimal icon style throughout the application.

Icons should be simple and understated, similar to the reference image.

Avoid mixing different icon styles.

Icons should support the text rather than unnecessarily replacing labels.

---

## Visual Density

The interface should have a moderate information density appropriate for a trading platform.

It should be possible to display meaningful amounts of financial information without making the UI feel crowded.

Use spacing to create structure, but do not make every section excessively large.

The goal is:

```text
High information density
        +
Strong visual hierarchy
        +
Generous enough spacing
        =
Professional trading interface
```

---

## Responsive Design Direction

The visual identity must remain consistent across desktop, tablet, and mobile.

The reference image primarily represents the desktop experience, but smaller screens should adapt the layout rather than simply shrinking it.

Multi-column layouts should naturally collapse into appropriate stacked layouts.

The application should continue to feel like the same trading product at every screen size.

---

## Design Consistency

Every new page, component, form, table, modal, dashboard, and feature should look as though it belongs to the same application shown in the reference image.

Do not introduce unrelated colors, visual styles, card treatments, typography styles, or component aesthetics.

When designing a new UI element that is not explicitly shown in the reference, infer its appearance from the established visual language.

The reference image defines the product's visual direction, not the exact page layout or content.

Preserve the overall identity:

**Premium fintech + modern trading platform + dark green foundation + bright green accents + clean white/light theme + rounded panels + subtle borders + strong financial data hierarchy.**
