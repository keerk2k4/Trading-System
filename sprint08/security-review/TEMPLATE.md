# OWASP Security Review Template

Use this template to document security findings and dispositions for each OWASP Top 10 category relevant to the authentication service.

## Categories

For each category, provide:
- **Finding:** What was checked and what was discovered. Use "none" if no issues found, but always name what was checked.
- **Disposition:** How the finding is handled. Use "accepted" if a residual risk is being carried, and explain the risk and why.
